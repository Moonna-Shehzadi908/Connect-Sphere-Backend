# ConnectSphere Frontend

A modern social networking platform frontend built with React, TypeScript, and Vite.

## Features

- Modern and responsive UI
- Authentication (Sign Up & Sign In)
- JWT Authentication Integration
- React Router Navigation
- Axios API Integration
- Reusable Components
- Clean Folder Structure
- TypeScript Support

## Tech Stack

- React
- TypeScript
- Vite
- React Router DOM
- Axios
- CSS

## Project Structure

```
src/
 ├── components/
 ├── pages/
 ├── services/
 ├── assets/
 ├── App.tsx
 └── main.tsx
```

## Getting Started

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Frontend runs on:

```
http://localhost:5173
```
